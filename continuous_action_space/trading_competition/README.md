# Trading Competition

Shared market-impact trading environment and comparison utilities for:

- Nash-DQN
- Locally linear-quadratic SRE-DQN

The canonical training notebook is `TradingCompetition_Training.ipynb`.
The canonical evaluation notebook is `TradingCompetition_Visualization.ipynb`.

Historical notebooks and imports in `continuous_action_space/locally_linear_quadratic`
are kept as compatibility wrappers.
